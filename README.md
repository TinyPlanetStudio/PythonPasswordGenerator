# PythonPasswordGenerator
A script to generate or store passwords in a editable file path.

How to use
1. Download the PasswordGenerator.py file
2. Run the file
3. Enter the file path in which you want your passwords stored
4. Follow the instructions in the script
5. Open the file path you set to have your passwords stored in
6. Open the password.password file, it just acts like a txt. You can open it in Kate, Notepad, or any other text editor of choice

You should see your passwords in that file
